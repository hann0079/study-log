### 확률변수의 특징
- 확률밀도함수
	- $P(X = x)$ ; $P(x)$
	- X의 관측값이 x일 확률
	- 예시
		- $P(X = 앞)$
	- 확률 계산
		- 각 수치에 몇이 분포했는지 
- 확률밀도함수
	- X가 연속형
- 확률질량함수
	- X가 이산형
	- 책에서는 둘 다 확률밀도함수로 통칭
- 확률밀도함수 P(x)의 특징
	- 확률은 0 이상 1 이하
	- 이산형 확률변수
		- 모든 관측값에 대한 확률을 더하면 1
	- 연속형 확률변수
		- 가능한 전체 범위에서의 확률밀도함수의 적분값(확률밀도함수 아래의 면적)이 1

### 기댓값과 분산
- 기대값; E(X)
	- 모든 가능한 X값을 그 확률로 가중치를 두어 더한 값.
	- 평균은 자료를 모은 후 계산한 값 
	  기대값은 확률을 이용하여 계산한 값
- 분산 ; Var(X)
	- 편차 제곱의 기대값. 자료가 평균으로부터 얼마나 떨어져 있는지(흩어져 있는지)를 나타냄.

### 정규분포 ; 가우스 분포
- 통계학에서 가장 중요한 분포
- 평균(μ)을 중심으로 좌우 대칭인 종 모양
- 평균(중심 위치)과 분산(퍼진 정도) 두 가지만 알면 분포가 결정
- 평균 = 중앙값 = 최빈값
- 왜도(비대칭도) = 0, 첨도(뾰족한 정도) = 0
- 표기
	- X∼N(μ,$σ^2$)
	- μ는 평균, σ는 표준편차
- ![[Pasted image 20260128123521.png]]

- 표준정규분포
	- 평균이 0이고 분산이 1인 정규분포
- 표준화(standardization)
	- 일반 정규분포 변수 X를 표준정규분포 변수 Z로 변환하는 과정
	- 내 점수(X)에서 평균(μ)을 뺀 후 표준편차(σ)로 나눈 것
	- 서로 단위가 다른 변수들을 비교할 때 필수
