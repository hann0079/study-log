- 기술통계
	- 수집된 자료의 특성을 평균, 표준편차와 같은 중심경향값과 산포도의 대표값으로 요약 · 정리
	- 결과를 모집단으로 추론 X

		- 결과를 통해 모집단의 특성을 추론

	- 표본에서 얻은 통계값을 모집단의 특징인 모수치 추론에 이용
- 표집이 이루어지는 통계분석
	- 표본을 통하여 모집단의 특성을 추론하고자 하는 것이 일반적

### 통계적 가설검정의 원리
1. 서로 대립되는 관계에 있는 영가설과 대립가설을 세우고
2. 연구자가 주장하는 대립가설이 옳다는 것을 보이기 위하여
3. 일단 영가설이 참이라고 가정하고 검정 시작
- 영가설; null hypothesis; 귀무가설; $H_0$
	- 다른 증거가 없을 때 사실로 여겨지는 가설
- 대립가설; alternative hypothesis; $H_A$
	- 연구자가 주장하는 가설
- ![[Pasted image 20260128110440.png]]
- 예시
	- 연구자는 실험집단과 통제집단의 평균이 다르다는 것을 보이고 싶음
	- 다른 증거가 없다면 실험집단과 통제집단이 프로그램 처치 후 차이가 없다고 생각
	- 영가설 - [^1]귀무가설
		- 두 집단 간 차이가 없다
	- 대립가설
		- 두 집단 간 차이가 있다
- 연구가설
	- 연구자가 주장하는 모집단의 특성에 대한 진술
- 예시
	- ![[Pasted image 20260128110842.png]]
	- 통계적 가설검정 절차
		- 영가설이 참
			- 실험집단과 통제집단의 평균이 같다는 조건 하에 진행
		- 연구자가 모든 자료 분석 결과
			- 집단 평균이 같다고 하기에는 확률적으로 매우 낮다는 분석결과
			- 영가설이 참이라고 가정한 것 - 영가설이 참이기 힘들다
			- 미리 정한 통계적 기준(유의수준)에 따라 영가설 기각 여부 결정
		- 결론
			- 두 집단의 평균이 같다는 영가설이 기각된다는 것
			- 실험집단과 통제집단의 평균이 다르다는 것

### 영가설, 대립가설, 단측검정, 양측검정
- 대립가설
	- 연구자가 주장하는 진술
		- 같지 않다, 차이가 있다
- 영가설
	- 대립가설의 반대
		- 같다, 차이가 없다
	- 다른 증거가 없을 때 사실로 여겨지는 가설
- 예시
	- 기존 설문조사 결과 
		- 평균 가정학습 시간이 2시간이다
	- 연구자가 주장하는 것
		- 평균 가정학습 시간이 2시간이 넘을 것이다
	- 대립가설
		- 평균 가정학습 시간이 2시간을 초과한다
	- ![[Pasted image 20260128111847.png]]
- 단측검정 ; one-tailed test 
	- 기각하는 것을 한쪽 방향으로만 검정
	- 대립가설이 '2시간보다 많다'인 경우
		- 영가설은 그 반대인 '2시간보다 적거나 같다'
	- 2시간보다 더 많은 경우에만 영가설 기각 가능
	- 2시간보다 적은 경우는 영가설 기각 불가
- 양측검정; two-tailed test
	- 대립가설이 '2시간이 아니다'인 경우
		- 영가설은 그 반대인 '2시간이다'
	- 2시간보다 많든 적든 영가설 기각 가능
- 예시
	- 영가설
		- 흡연자의 비율이 15%다
	- 대립가설
		- 흡연자 비율이 15%가 아니다
	- ![[Pasted image 20260128112702.png]]

- 제 2종 오류

	- 1 - $\alpha$
- 제 2종 오류 확률 ; 영가설이 참이 아닌데 영가설을 기각하지 않는 확률 
	- $\beta$
- 검정력 ; 영가설이 참이 아니라서 영가설을 기각하는 확률 
	- 1- $\beta$
- 확률 설정
	- 제1종 오류가 제2종 오류보다 더 심각함
	- 제1종 오류인 $\alpha$를 제2종 오류인 $\beta$보다 낮게 설정
	- 자료 모으고 통계적 분석 시작 전 설정
		- $\alpha$ = 0.05 (5%)
		- $\beta$ = 0.20 (20%)
