타깃이 평균 정도를 예측하는 수준이라면 (분자와 분모가 비슷해짐 ⇒ 1에 가까워짐)
R$^2$은 0에 가까워지고, (1에서 빼기 때분에)
예측이 타깃에 아주 가까워지면 (분자가 0에 가까워짐)

- score() 메서드의 값이 높을수록 좋은 것
	- 정확도, 결정계수
- 만약 score() 메서드가 에러율을 반환한다면
  실제로는 낮은 에러가 socre() 메서드로 반환될 때 높은 값이 되도록 바꾸기

### 최근접 이웃 회귀
- 예측 - 주변 이웃 n개의 평균값 산출
- 새로운 샘플이 훈련 세트의 범위를 벗어나면 엉뚱한 값이 나옴 (더 작게 or 더 크게)

### 선형 회귀
- 특성이 하나인 경우, 그 특성을 가장 잘 나타낼 수 있는 직선을 학습하는 알고리즘
- 머신러닝에서 기울기를
  계수(coefficient) 또는 가중치(weight)라고 부름
- ![[Pasted image 20260114161936.png|300]]
- 직선을 그리려면 기울기와 절편 필요
	- y = a * x + b
	- x가 농어의 길이, y가 농어의 무게 
	- x가 하나의 특성이 됨
	- 이 데이터에 가장 잘 맞는 a, b를 LinearRegression 클래스가 찾음
		- 객체의 coef_와 intercept_ 변수에 저장됨

- 모델 파라미터
	- 머신러닝 알고리즘이 찾은 값
		- coef_, intercept_
	- 머신러닝 알고리즘의훈련 과정은 최적의 모델 파라미터를 찾는 것과 같음
		- 모델 기반 학습
	- k-최근접 이웃에는 모델 파라미터 없음
	- 훈련 세트를 저장하는 것이 훈련의 전부
		- 사례 기반 학습
