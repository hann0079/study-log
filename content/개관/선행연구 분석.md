- 비슷한 주제로 진행된 연구, 선행연구를 살펴보고 연구계획 수립
- 그 주제로 이미 진행된 연구를 읽어 보면 
  **어떤 연구문제에 대하여 어떤 연구방법을 써서 어떤 결론을 도출**했는지 정보를 얻을 수 있고,
  **연구가 더 필요한 문제**가 무엇인지 확인 가능
- 연구의 방향을 잡고 전체적인 틀을 다듬는, 연구에 있어 매우 중요한 단계
### 연구범위 제한
1. 키워드 검색
2. '제목', '초록' 보면서 자세히 볼 연구(논문) 선택
3. '서론'에서 연구문제를 확인, 선행연구 훑어보기
4. '연구방법'에서 연구대상, 변수와 측정도구, 분석방법 등 읽기
  ⇒ 내 연구의 범위 제한(연구대상과 지역 한정 등)
  - 연구범위를 너무 많이 제한하여 얻은 연구결과는 일반화가 쉽지 않음 ⇒ 결과 해석 시 주의 필요
  - 연구보고서에 연구범위를 어디까지로 제한하고 얻는 결과인지 언급하여 연구결과 과대 해석 주의
### 연구문제 수정
- 선행연구 분석으로 연구범위 제한 후 연구문제 수정
- 연구 문제 더욱 구체화 필요
	- 선행연구의 변수 분석 ⇒ 키워드를 더 추가하여 검색 (카페 + 이용/특징/특성 등)
	- 주로 사용되는 변수 확인 (카페 이용 목적, 카페의 특징, 고객만족도 등) ⇒ 자신의 연구목적에 더 적합하도록 연구제목 구체화 
### 변수 선택
- 연구에서 사용할 변수의 유형 및 내용 결정, 측정도구 선택
- **선행연구에 사용된 변수, 측정도구**가 자신의 연구문제에 적합하다면 **인용하여 사용**
- 기존 **검사도구의 내용을 수정 또는 번안**할 필요가 있는 경우
	- 본인 연구문제에 맞게 검사도구의 어휘, 문항을 수정
	- **전문가의 검토**를 통해 내용타당도를 확인하고
	  요인분석 등 통계적 분석을 실시하여
	  **검사도구의 신뢰도와 타당도 확인 필요**
